# Overview

This course is an introductory course to both Python and the art of programming.

I expect that you already know the basics of Python syntax, how to write a basic for loop, how to define functions.

We will learn about three different styles of Python programming: procedural, object-oriented, and functional.  We will learn about low-level memory management all the way up high-level concepts like decorators, custom packages, and web services.

*If you already know all of this, you should perhaps seek placement in **Dr. Troy's Intermediate Python** instead.*
